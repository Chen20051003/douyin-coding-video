## 卡点 · 1080×1920

| 项 | 值 |
|---|---|
| 画幅 / 帧率 | 1080×1920 / 30fps |
| 时长 / BPM | 24s / 128 BPM |
| 一拍 | 0.46875s；**每 2 拍一刀 = 0.9375s** |
| 安全边距 | 左右 56px；顶部 90px；底部 160px |
| 主色 | 酸性绿 `#C6FF3D`、紫 `#8B6BFF`、粉 `#FF5C8A`、青 `#5EE7FF` |
| 镜头 punch | 每拍 `1 + 0.012·exp(-phase·7)` |
| 底部频谱 | 64 段，y=1760，段落随拍脉冲 |
| 字体 | 标题 Noto Sans SC 900；代码 Consolas 600 |

镜头（12 个，每 0.9375s 左右）：倒计时 → 标题 → 输入 → 生成 → 写码 → 写码 → diff → 测试 → 构建 → 1.2s → push → DEPLOYED → SHIP IT。
