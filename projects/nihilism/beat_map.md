# 爆点结构 ·《虚无主义》v3（前置版）

## 主爆点

**DROP = 57.638s**，加缪「世界是荒诞的，但不必投降」开口的瞬间。  
比 v2 的 70.892s 提前约 13.3 秒，后面还有 25 秒可以承接、落地、收尾。

## 时间轴

| 时间 | 音频 | 画面 |
|---|---|---|
| 53.80s 起 | 8 分音符 kick 渐进 + 军鼓滚奏 | 哲学家双卡保持，镜头缓慢推进 |
| 55.20–57.40s | BGM 从 1.0 压到 0.38 | 画面转暗，拆句字卡：世界 / 是 / 荒诞的 / 但不必投降 |
| 57.42–57.60s | **0.17 秒微呼吸**（不是长黑场） | 只留金色横线与最后一个字 |
| 57.598s | 冲击点比人声早 1 帧：低频 boom + riser | 镜头 punch，冲击波 |
| 57.638s | 人声进入「加缪说：世界是荒诞的」 | 巨型「荒」字爆开，暖闪而非全白 |
| 58.0–59.0s | BGM 恢复，鼓组继续 | 「荒」字退为背景，卡片与字幕回来 |
| 62.408s | 西西弗段加一次中重音 | 石头/斜坡推进 |
| 70.892s | 「意义是被做出来的」只做普通重音 | 不再二次大爆，让主题句落地 |

## 为什么这样改

1. **不迟**：爆点放在 57.6s，视频还有 25 秒，观众有反应时间。
2. **不生硬**：爆点前有 4 秒 8 分音符鼓组渐进 + 军鼓滚奏，不是突然从静音砸下来。
3. **有呼吸但不黑屏**：0.17 秒微呼吸，保留金色横线，避免“断片感”。
4. **提前 1 帧**：冲击点比人声早约 33ms，听感更紧。
5. **只炸一次**：70.9s 的主题句不再爆，避免“每段都在炸”的疲劳。
