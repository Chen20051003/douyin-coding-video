# v2 爆点结构 ·《虚无主义》

## 核心落点

- **DROP = 70.892s**，第 17 句「意义不是被找到的，是被做出来的」开口的瞬间。
- 前面不是继续堆鼓，而是 **压住 → 拆句 → 留白 → 重拍**。

## 时间轴

| 时间 | 音频 | 画面 |

## 第二次重音

- **HIT = 19.874s**，「上帝死了」报纸落版。
- 低频 boom + 纸张拍击 + 红色闪帧 + 镜头抖动；不抢主 drop，只做第一次“砸下”。

## 设计原则

1. 卡点不是每拍切一刀，而是 **能量曲线**：先让观众以为要炸，再抽掉声音。
2. 留白必须真留：BGM 与 SFX 都降到 0，只留 0.28 秒黑场。
3. 爆点必须落在 **内容重音** 上，而不是随便一个小节头。
4. 爆点后不立刻继续堆，留 1.5 秒让「造」字和字幕呼吸。
